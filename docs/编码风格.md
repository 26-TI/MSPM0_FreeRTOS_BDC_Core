## 1. 命名约定

### 1.1 基本规则

| 类别 | 风格 | 示例 |
|------|------|------|
| 类型（结构体、枚举、联合、typedef） | 大驼峰（无下划线） | `RtListData`, `TimerHandle` |
| 函数、变量名 | 全小写 + 下划线分隔 | `rt_thread_self`, `max_count` |
| 宏定义 | 全大写 + 下划线分隔 | `RT_TRUE`, `MAX_LOG_LENGTH` |
| 类内/结构体内成员 | 前加下划线（可选） | `_data`, `_next` |

**示例：**

```c
/* 类型定义（大驼峰） */
typedef struct TimerNode {
    struct TimerNode *_next;
    uint32_t _timeout;
} TimerNode_t;

/* 函数名（小写+下划线） */
void timer_node_init(TimerNode_t *node, uint32_t timeout);

/* 变量名（小写+下划线） */
static uint32_t max_count = 100;

/* 宏定义（全大写+下划线） */
#define ABS(x)   ((x) > 0 ? (x) : -(x))
```

### 1.2 缩写规则

| 规则 | 示例 |
|------|------|
| 短单词可去元音 | `temp` → `tmp` |
| 长单词取前几字母 | `increment` → `inc`, `initialize` → `init` |
| 使用常见缩写 | `message` → `msg`, `password` → `pwd` |
| 避免单字母 | 循环变量 `i`, `j` 除外 |

> ⚠️ **禁止使用汉语拼音或拼音首字母**。

### 1.3 本工程文件命名

| 层级 | 命名格式 | 示例 |
|------|---------|------|
| BSP 层 | `bsp_模块.cpp` / `bsp_模块.hpp` | `bsp_can.cpp`, `bsp_uart.hpp`, `bsp_pwm.hpp` |
| Device 层 | `设备名.cpp` / `设备名.hpp` | `can_motor_device.hpp`, `can_dc_motor.cpp`, `can_stepper_motor.hpp` |
| Device 配置 | `bsp_cfg.cpp` / `bsp_cfg.hpp` | 全局实例声明与 `bsp_init()` |
| Algorithm 层 | `算法名.cpp` / `算法名.hpp` | `pid.cpp`, `pid.hpp` |
| Protocol 层 | `协议名_proto.cpp` / `协议名_proto.hpp` | `can_motor_proto.cpp`, `protocol_uart.hpp` |
| App 层 | `main.cpp` / `main.hpp` | FreeRTOS 任务入口 |

> C++ 头文件用 `.hpp`，纯 C 头文件用 `.h`。

### 1.4 本工程函数命名

| 层级 | 风格 | 示例 |
|------|------|------|
| BSP 公开接口 | 小写 + 下划线 | `bsp_can_init()`, `bsp_uart_send()` |
| FreeRTOS 任务函数 | 小写 + 下划线 | `ctrl_task()`, `can_rx_task()` |
| C 全局函数 | 小写 + 下划线 | `bsp_init()`, `motor_can_dispatch()` |

### 1.5 禁止事项

- 禁止 `a`, `b`, `w` 等单字母变量名（循环变量 `i`, `j` 除外）
- 禁止汉语拼音或拼音首字母
- 禁止无意义的命名如 `data1`, `tmp2`

### 1.6 C++ 补充

C++ 代码沿用以上 C 命名约定：

- **类名**：大驼峰，如 `MotorDevice`, `DcMotor`, `StepperMotor`, `Pid`
- **枚举类**：大驼峰，如 `MotorMode`
- **命名空间**：暂不使用
- **成员变量**：前缀 `_`，如 `_motor_id`, `_speed_pid`
- **成员函数**：小写 + 下划线，如 `set_speed_pid()`, `get_data()`

## 2. 缩进与空格

- **缩进**：使用 2 个空格（不使用 Tab，或统一将 Tab 转为空格）
- **花括号**：单独占一行，与引用语句左对齐
- **空格规则**：
  - 运算符两侧加空格：`if (x <= y)`
  - 关键字（`if`, `for`, `while`, `switch`）后加空格
  - 括号内表达式**两侧不加空格**：`if (x <= y)` 正确，`if ( x <= y )` 错误
  - 函数调用括号前不加空格：`rt_thread_self()` 正确

**示例：**
```c
/* 正确 */
if (condition)
{
    do_something();
}

for (i = 0; i < MAX; i++)
{
    /* 循环体 */
}

/* 错误 */
if(condition){
    do_something();
}
if ( condition ) { ... }
```

**switch 特殊格式：** case 与 switch 对齐
```c
switch (value)
{
case 1:
    /* code */
    break;
case 2:
    /* code */
    break;
default:
    break;
}
```

**单行语句：**
```c
/* 正确 */
if (condition)
    do_something();

/* 允许加括号 */
if (condition)
{
    do_something();
}

/* 错误：写在同一行 */
if (condition) do_something();
```

**空循环：**
```c
while (busy_flag) {}   /* 正确 */
while (busy_flag);     /* 错误 */
```

## 3. 注释

- **文件头**：包含版权、许可、修改记录
```c
/*
 * Copyright (c) 2006-2025, YourTeam
 * SPDX-License-Identifier: Apache-2.0
 *
 * Change Logs:
 * 2025-01-10  Author  first version
 */
```

- **函数头**：说明功能，可标注作者
```c
/* 系统初始化，须在启动时调用一次 */
void system_init(void);
```

- **宏定义**：必须有注释
- **非约定俗成的缩写变量**：定义处注释说明
- **switch 中 fall-through**：必须注释原因
```c
case 0:
    /* fall-through 允许 */
case 1:
    break;
```

- 注释置于代码**上方或右侧**，与代码间**不留空行**
- 修改代码时**同步更新注释**

## 4. 文件组织

- 每个模块独立 `.c` / `.h` 文件
- `.h`：类型定义、函数声明、外部变量声明（`extern`）
- `.c`：变量定义、函数实现、内部声明

**示例：**
```c
/* module.h */
#ifndef __MODULE_H__
#define __MODULE_H__

typedef struct {
    int id;
} ModuleHandle_t;

extern int public_var;   /* 声明外部变量 */
void module_init(void);  /* 对外接口 */

#endif

/* module.c */
#include "module.h"

static int private_var;          /* 内部变量 */
int public_var;                  /* 全局定义 */

static void internal_func(void); /* 内部函数声明 */

void module_init(void)
{
    /* 实现 */
}

static void internal_func(void)
{
    /* 实现 */
}
```

## 5. 函数设计

- 函数尽量简短，只完成单一功能
- 参数为空时显式写 `void`
- 避免三个以上的连续空行
- 谨慎使用日志输出，正常情况下应关闭，通过宏开关控制

## 6. 完整代码示例

```c
/* timer.h */
#ifndef __TIMER_H__
#define __TIMER_H__

#include <stdint.h>

/* 类型：大驼峰 */
typedef struct TimerNode {
    struct TimerNode *_next;
    uint32_t _timeout;
} TimerNode_t;

/* 宏：全大写+下划线 */
#define TIMER_INFINITE  0xFFFFFFFFU

/* 函数声明：小写+下划线 */
void timer_node_init(TimerNode_t *node, uint32_t timeout);
void timer_start(TimerNode_t *node);

#endif

/* timer.c */
#include "timer.h"

static TimerNode_t *timer_list = NULL;   /* 内部变量 */

/* 内部函数声明 */
static void insert_timer(TimerNode_t *node);

void timer_node_init(TimerNode_t *node, uint32_t timeout)
{
    if (node == NULL)
        return;

    node->_next = NULL;
    node->_timeout = timeout;
}

void timer_start(TimerNode_t *node)
{
    if (node == NULL)
        return;

    insert_timer(node);
}

static void insert_timer(TimerNode_t *node)
{
    /* 实现插入逻辑 */
    while (timer_list != NULL) {}   /* 空循环示例 */
}
```

## 7. 禁止事项

- 除doxygen的块注释和分隔注释之外，不使用 `//` 以外的注释风格。
- 不在代码中连续使用三个以上空行
- 不将单条语句与 `if` 写在同一行
- 不省略可读性所需的空格
